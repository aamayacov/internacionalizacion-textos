# Internacionalización UVP

Prototipo multipágina del ecosistema de Internacionalización de la Universidad del Valle de Puebla.

## Páginas

- Inicio
- Movilidad
- Experiencias
- Cooperación
- Convocatorias
- Recursos
- Estudia en UVP
- Solicitar orientación

El sitio es estático y puede publicarse directamente con GitHub Pages desde la rama `main`.
